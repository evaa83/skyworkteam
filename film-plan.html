資料標示原則

公開背景是歷史記載，不代表今日現況；主辦提供是待向本人核對的前訪線索；製作建議是提問與拍攝方向，不是預設答案。網頁出現過不代表已取得受訪或圖片使用同意。

A 組｜《在山裡成家的這一家》

主角：何冠杰、阿珍姐及其家庭。故事從家庭日常出發，探索世代、耕作、住處與沿線互助如何改變。

公開背景與故事線索

A1｜果園也是路上的食宿據點

旅遊作者「老蝦」2022/7/28 發表、頁面標示 2026/1/1 更新的紀錄，介紹慈恩隧道何家果園的水果、便當與住宿，以及山友停留經驗。可據此追問家庭如何從耕作延伸到接待；價格與設施不能直接當成現況。

來源：〈中橫四辣羊頭山住宿推薦｜慈恩隧道何家果園民宿〉｜旅人紀錄，非人物專訪。

A2｜接待旅人的小事，可能比家族簡介更有故事

2017/12/10 健行遊記記下慈恩果園食宿、家常用餐及主人關心獨行旅人的互動。文章未具名，不能把主人直接認定為何冠杰或阿珍姐。

來源：〈一個人的流浪之旅 D3：慈恩→洛韶〉｜第一人稱遊記。

前訪：把文章交給家人辨認當時接待者，再問是否有印象深刻的客人或互助經驗。不將遊記中的「唯一住宿點」等概括描述當成今日事實。

A3｜團體健行與長年的地方記憶

救國團 2019 年營隊答客問把慈恩何家果園列為第二天所在地，顯示曾納入團體行程。2012 年背包客棧討論亦有自稱家屬及舊住客的留言，談到果園、搭伙與第二代管理；帳號身分、綽號尚無法和目前名單核對。

來源：108 年暑期營隊 Q＆A｜單位歷史文件；〈重回慈恩山莊〉，2012/5/18 附近留言｜匿名尋訪線索。

人物在片中的作用與前訪問題

何冠杰｜現在生活與沿線關係的主要人物

主辦提供：第二代目前在山上生活並有家庭，可能協助查看路況，與沿線工作者及旅人往來。

要挖的內容：現在實際做哪些工作、如何安排家庭，以及一件能說清楚「誰找他、他做什麼、後來如何」的互助事件。

  • 「你現在一週裡做最多的事是什麼？這些工作怎麼開始的？」
  • 「最近一次有人請你幫忙，是什麼完整經過？」
  • 「你一直住山上，還是曾經離開再回來？成家後最需要安排什麼？」

可拍：帶路、物資整理、接待、照顧土地等當日真實行動。道路協助內容須確認，不為拍攝特別安排巡查。

阿珍姐｜家庭歷史與下山選擇的主要人物

主辦提供：與先生早年在山上生活、耕作及賣水果；目前已下山。不可再設定成現今常駐山上的人。

要挖的內容：最初如何上山、成家與養育的條件、交接下一代的過程，以及現在如何看待山上的家。

  • 「剛上山時一天怎麼過？最難解決的是什麼？」
  • 「哪一次收成、接待或家庭事件，現在仍很清楚？」
  • 「什麼時候決定下山？有哪些習慣或東西跟著您一起下來？」

可拍：由本人選擇的舊照、農具或物件；訪談按她目前住處、意願及交通安排，不預設為拍片返山。

網路仍未核實

未找到能以全名直接核對兩人完整生平的公開專訪。四代關係、獼猴影響、颱害與轉作時間、路況協助、工程人員食宿及雪季服務，目前屬主辦線索。先畫家族及事件時間線，再向本人逐項確認，避免把轉作寫成單一原因。

故事順序：何冠杰現在的一項工作 → 阿珍姐與早年的家 → 生活條件與世代改變 → 一次具體互助事件 → 這個家庭接下來的安排。

A 組行前成果：家庭關係圖、事件時間線、三件待追問事件、可拍行動及舊物清單。兒童不預設受訪或入鏡。

B 組｜《把山居過成自己的日子》

主角：陳光、劉玲。兩人如何用各自的能力，解決每天的生活問題，又如何一起安排生活？

公開背景與故事線索

B1｜製簫與交流：山居也有向外的連結

2010 年工坊介紹將陳光列為洞簫、尺八及竹笛製作者，記載演奏家到洛韶交流；2011 年第二屆仍列他參與。可追問如何學習、試作、接收回饋，以及作品如何連結外地同好。

來源：2010/7/15 工坊與講師介紹；2011 年第二屆洞簫尺八工坊｜歷史活動資料，不代表目前仍舉辦。

B2｜竹林、移居與夫妻不同的起點

2020/4/15 網址所示刊載的綜合報導記述：陳光曾從事農業及海外工作，返臺後因竹林選居洛韶；劉玲起初反對，後來投入果實與植物發酵飲品。文中也提到製簫的等待與兩人的採補生活。

來源：〈隱身竹林的製簫高人 陳光〉｜刊載日未必是原始採訪日；年齡、居住年數不能直接當作現況。

製作推論：從夫妻各自的山居選擇進入，不沿用報導的隱士形象，也不把劉玲設定為丈夫的配角。

陳光｜以手藝與判斷處理材料、也處理生活的人

要挖的內容：目前做哪些工作、一次試作或修正，以及創作與生活技術有無關係。收入來源、是否仍製簫均需確認。

  • 「現在做最多的是什麼？有哪件還沒完成的東西可以看？」
  • 「最近一次做不好的地方，怎麼判斷、試了什麼方法？」
  • 「哪些生活問題自己解決，哪些還是要靠別人？」

可拍：完整的一段當日工作，全景、中景、手部與工具聲。長期製程不要求在短時間內重演或假裝完成。

劉玲｜擁有自身工作、感受與選擇的共同主角

要挖的內容：現在的工作、社交、喜歡與不便；生活如何逐步熟悉，今天有哪些安排是她自己的選擇。

  • 「以前報導這樣寫，您覺得漏了什麼、現在又變了什麼？」
  • 「一天裡哪段時間最屬於自己？哪些事是您決定的？」
  • 「您會選哪項自己研究的生活方法介紹給第一次來的人？」

可拍：由她選擇的手作、飲食、整理、種植或其他日常；夫妻先各自訪談，再自然交流，不誘導對立。

主辦提供、待確認的線索

引擎零件、柴油與改造爐具這次未找到可核對來源；器材、燃料與目前是否使用須先確認，不寫成技術事實。主辦稱果醋，舊報導稱發酵飲品，產品種類與現況須詢問，不加健康功效宣稱。西寶國小只可能作舊生活經歷背景，沒有重新列入採訪名單。

故事順序：一項正在解決的生活任務 → 夫妻為何來到這裡 → 各自能力與共同協作 → 今日喜歡、不便與未來安排。

B 組行前成果：夫妻各自的提問表、作品及生活技術線索清單、可拍流程；詢問本人持有的照片與工坊紀錄，不直接挪用網站圖片。

C 組｜《因工作而來，在山裡留下的人》

主角：觀雲山莊工作人員 陳進旺。工作如何成為他與山的關係？

人物定位與前訪方向

C1｜由工作看見人與山的關係

依主辦本次更新，C 片以觀雲山莊工作人員陳進旺為主角。觀雲山莊是他的工作場域，影片由他個人的日常、選擇與關係展開。職務細項、年資、到職原因及過往工作經歷，須在前訪向本人確認。

C2｜一段能被看見的日常工作

先請陳進旺介紹自己實際負責的工作，再選擇一段能完整跟拍的流程，例如準備、接待、整理或交接；不預設他負責所有部門。以具體行動呈現高山工作需要的能力，以及與同事、旅人、沿線居民的互相依靠。

C3｜山上工作之外的生活

  • 「當初為什麼來觀雲山莊？來之前的生活是什麼樣子？」
  • 「工作日住哪裡、休假怎麼安排？哪些人對您很重要？」
  • 「山上工作最熟悉的一件事，以及最需要應變的一件事是什麼？」
  • 「道路、天候或旅客量改變時，您親身經歷過什麼？那一天如何度過？」
  • 「為什麼繼續在這裡工作？未來想保留或改變什麼？」

可拍：本人允許且不影響工作的行動、與同事或旅人的互動、山莊環境及工作結束後的片刻。工作區及其他入鏡者先取得同意。

背景資料使用範圍

先前天祥青年活動中心的建築、休館及員工留守資料，不再作為陳進旺個人故事的背景依據。同名公開資料不能直接連結為他的經歷；涉及過往任職或特定事件，先向本人核對。

故事順序：一段當日工作 → 為何來到山莊 → 工作之外的生活與牽掛 → 一件親歷的變動 → 現在如何繼續。

C 組行前成果：陳進旺人物小傳、工作與生活時間線、三件具體事件、可拍工作流程及照片清單。訪談時間、地點與工作區拍攝方式另行協調；在觀雲住宿期間可依實際排班安排補拍。

三組如何共同拍攝

12–14 人分三組。每場由主角所屬組主責，其他兩組分別支援「環境與行動」及「關係、細節與聲音」，到下一場輪替。依場地與本人接受度決定是否全員同行；全員到場也不全部圍在受訪者旁。

任務交付素材
主責組：提問、主畫面、收音、紀錄完整訪談、答案時間點、待補畫面清單
支援一：環境、人物行動、流程場域全景、中景及連續工作畫面
支援二：互動、反應、物件、現場聲自然發生且同意拍攝的互動、細節與聲音，附內容標記

訪談前後集中拍工作行動，避免干擾收音。共同素材優先交主責組彙整，其他片有需要且符合使用同意時亦可使用，不強求三片共用所有畫面。第一天攝影教學對應訪談、行動、環境、互動、細節與聲音六種元素。

論壇與輔助人物的使用

林冠宏提供農業條件，許育誠補充現場生態，張木林（陳添財，已確認參加）解釋植被與環境變化；鄭明岡以接待、工作者及地方關係提供經驗。論壇內容依三片的實際問題選用，不為了涵蓋每位講者而放入。前主廚、加油站、工程及警政人員可補充具體資訊；前財務／助理仍以交流引介為主，正式受訪另議。

共同前訪交付與來源紀錄

  1. 姓名、偏好稱呼、居住工作及家庭時間線，分清親歷和轉述。
  2. 三件具體事件：何時、何地、哪些人、做了什麼、後來如何。
  3. 一段現在能拍的真實行動，以及可自然互動的人。
  4. 可展示的照片、工具、文件，記錄持有人與使用同意。
  5. 將主辦線索與網路記載交本人補充、更正，不要求答案吻合大綱。

本輪搜尋：慈恩／何家果園／何冠杰與何冠傑／阿珍與阿真／洛韶陳光劉玲／製簫／天祥青年活動中心地震員工。同名外地果園、同名學者均排除。本節研究的是三個主角方向；未將論壇講者列為新主角，也未重新展開其完整生平調查。

網路照片及文字只作研究，入片另確認授權。來源在各段附直接連結；歷史資料與拍攝當下的情況必須分開。

整體製作流程｜從活動前準備到三支影片

本節為建議工作流程，尚非已確認時段表。以三組、三支人物影片為單位；AI 前製素材、現場實拍與論壇發言，最後共同服務人物故事。素材數量與樣片秒數是起步建議，不是每支影片必須填滿的配額。

先確定內容，再決定如何加工

優先使用「舊照片＋本人聲音＋輕微動態」呈現記憶。簡單推近、平移、時間線與地圖，用一般剪輯／動畫即可完成；只有確實需要景深或影像延伸時才評估生成 AI。人物現在的生活、工作及互動留給現場拍攝。

階段三組的任務主辦／指導者的工作完成後應有什麼
活動前｜確認主角與前訪A、B 核對家庭／夫妻故事；C 前訪觀雲山莊工作人員陳進旺。各準備三件具體事件與一段可拍行動協調窗口、訪談及場地；確認陳進旺可拍的工作與個人記憶素材人物小傳、時間線、採訪問題與拍攝條件
活動前｜收集原始素材每組先收 5–10 件照片、錄音、短片或物件紀錄，逐件建卡協助核對來源、當事人意願與使用範圍原檔、素材資料卡、可用與待確認清單
活動前｜試剪與 AI 測試每組先做一段 20–30 秒樣片；先用靜照與前訪聲音，再判斷是否需要生成由攝影／剪輯指導者檢查內容、畫面與聲音；涉及人物及事件請本人核對三段內部樣片、加工紀錄、錯誤及待補畫面表
第一天｜共同教學與論壇取材看樣片，練習區分訪談、行動、環境、互動、細節及聲音；分工記錄論壇可用段落攝影師短示範；協調錄影與剪輯使用同意，確保論壇收音與錄影有人專責三組任務表、論壇時間碼、各片要追問的問題
田野拍攝｜依實際行程輪替主責組拍完整訪談；另兩組支援環境行動與互動細節。按舊照清單補拍現在的對照畫面管理場地、人流、受訪者負荷與收音；不為補足大綱要求重演可連續剪輯的人物行動、訪談、環境聲及鏡頭紀錄
每日整理｜拍攝後共同回顧先備份與命名，再選片；標記缺少的證據、鏡頭、聲音與疑問確認至少兩份不同儲存位置的副本，安排可行補拍每日素材表、故事修正與次日補拍清單
成果剪輯｜活動內先完成可放映版本人物故事先成形，再放論壇與 AI 素材；補字幕、來源與 AI 標示協助查證、技術檢查及成果放映；公開版若仍有待核對內容，另排活動後完成三支活動成果版；待修項目表與公開版交付安排

A 組｜何家果園：以前的家，如何走到現在

先找的原始素材製作方式片中作用與現場接點核對重點
阿珍姐與先生早年在果園、住家或攤位的照片優先一般推近／平移；必要時試輕微景深，人物不動作引入上一代生活，配阿珍姐回憶；現場拍物件或現在的家人物、地點、約略年份、持有人
不同時期家庭合照依年代呈現，配姓名與簡單家庭關係圖交代世代、誰上山誰下山；接何冠杰今日生活先核對四代關係及各人使用同意
種植、採果、裝箱與賣水果舊照推近果樹、農具與攤位，不新增採收動作讓耕作有畫面；現場拍目前土地與實際作物作物、季節與轉作時間；不預設一月能採果
舊屋、道路、果園入口舊照動態化，預留和同角度實拍銜接呈現空間與生活功能改變重拍位置可辨識且允許到達；不生成歷史地貌
健行者、聚餐、食宿及留言紀錄照片序列、文字局部呈現；AI 不補寫內容帶出沿線照應；接當下真實接待人物與事件身分；個資、照片及文字使用同意
已核對事件與空間資料一般時間線／簡單路線動畫整理時間與地點，不讓資訊壓過人物日期、地點與地圖素材來源

第一段測試：一張早年生活照＋一張家庭照＋一張果園照，配阿珍姐前訪聲音，做 20–30 秒「以前的家」。先確認故事與照片是否相符。

先不生成：獼猴吃水果、落石、雪季協助、公務人員住宿等具體事件。先確認事實並找原始紀錄；若未來確需重建，另行規劃並明確標示，不能作歷史證據。

B 組｜陳光、劉玲：為何而來，如何變成家

先找的原始素材製作方式片中作用與現場接點核對重點
移居前、初到洛韶的夫妻／家庭照片照片推近，按兩人各自敘述選取局部呈現不同起點；接現在各自的日常分別核對感受，不把一人的記憶寫成共同感受

工坊、樂友與交流照片照片序列與必要的年月／地點標記表現山居的對外連結活動時間、照片持有人及其他人物使用範圍
劉玲的手作、發酵飲品、擺攤照片推近材料、容器及攤位建立她自己的工作線；接她選擇的今日活動產品名稱與現況；不加健康功效
生活改造物件舊照照片與今日實物銜接引入生活難題與解決方法先確認物件、燃料、用途，不要求啟動或重演

第一段測試：兩人各選一張重要照片，各錄一段說明，製作兩段約 15–20 秒的記憶片段。先看見兩人的不同聲音，再決定如何交織。

先不生成：精確製簫工序、爐具燃燒、器材運作或人物吹奏動作。實拍真實操作；舊照片不生成口型或替人物表演。

C 組｜觀雲山莊陳進旺：以本人照片連結工作與記憶

先找的原始素材製作方式片中作用與現場接點核對重點
主角初到職及不同時期的工作照依年份動態呈現交代工作如何成為長期生活；接現在本人由陳進旺確認年代、人物及工作場域，不生成虛構人生
舊櫃臺、客房、廚房及熟悉空間推近並預留現在同角度畫面讓空間承載個人工作記憶部門、時間、本人是否在此工作
團體接待、旅客照片照片序列呈現不同工作場景補足過去節奏；接主角描述單張照片不能代表全年住房率或整體觀光

主角自願提供的生活照簡單動態呈現補足工作之外的人際、休息與牽掛個人及他人意願，不強求私領域

第一段測試：主角選定後，以一張早年工作照＋一張現在照片＋本人聲音做約 20 秒人物介紹。沒有舊照也可以靠實拍成片，不用生成假過去。

先不生成：員工留守、受困旅客、救援或地震災況。現在的空走廊不生成為歷史停業畫面；歷史與當下明確分開。

素材資料卡與檔案管理

每件原始素材先建卡，再加工；不知道的資訊寫「待確認」。原檔保留，修復、動畫與生成輸出另存，不能覆蓋。

一張資料卡需要的欄位

素材編號／所屬組別／原始檔名／提供者與持有人／人物／拍攝日期或約略年代／地點／事件說明／資訊確認人／使用範圍與同意紀錄／待核對事項／預計片中作用／需要補拍的鏡頭。

加工後增加：處理方式（一般動態或 AI）、工具與版本、生成日期、提示詞、輸出檔名、改變了什麼、檢查結果、本人核對狀態及成片標示。

共同測試提示詞

以原照片為唯一視覺依據，保留人物五官、服裝、物件、建築及文字。不新增人物或事件，不生成說話或工作動作。僅做緩慢推近與輕微鏡頭位移，呈現歷史照片的觀看感。

提示詞不能保證模型遵守。逐格檢查五官、手部、文字、物件及背景；改變史實或無法修正時，改用原照與一般鏡頭運動。正式展示以「歷史照片・動態呈現」區分實拍；AI 生成或重建另標「AI 動態化／AI 示意」，不作歷史證據。

第一輪如何驗收

  1. 故事：這段素材回答哪個問題？拿掉後是否影響理解？
  2. 事實：人、時、地有無確認？本人能否指出錯誤或補充？
  3. 畫面：有無多出人物、扭曲五官、變造器物或文字？
  4. 聲音：原聲、配樂、暫代旁白清楚區分，來源與使用範圍有紀錄。
  5. 拍攝接點：知道到現場要補哪一個角度、行動或聲音，不把 AI 當成已完成現場紀錄。
